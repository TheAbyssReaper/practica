# Telegram AI Quiz Bot

Telegram-бот для автоматической генерации учебных квизов по документам и FAQ-базе знаний. Бот принимает файл или выбранную тему из базы знаний, генерирует тестовые вопросы с помощью Gemini и проводит интерактивный квиз прямо в Telegram.

## Возможности

- Генерация тестов по загруженным документам.
- Поддержка файлов `.txt`, `.pdf`, `.docx`.
- Генерация квизов по FAQ-базе знаний.
- Выбор категории и темы через inline-кнопки Telegram.
- Вопросы с 4 вариантами ответа: A, B, C, D.
- Проверка ответа, объяснение правильного варианта и итоговый результат.
- Поддержка прокси через переменную `PROXY_URL`.
- Отдельный CLI-режим для обработки документов без Telegram.

## Стек

- Python 3.10+
- python-telegram-bot
- Google Gemini API
- python-dotenv
- PyPDF2
- python-docx

## Структура проекта

```text
.
├── teacher_bot.py          # Telegram-бот: команды, кнопки, квиз, обработка файлов
├── pipeline.py             # Загрузка документов, чанкинг, генерация вопросов через Gemini
├── .env                    # Локальные переменные окружения
├── quiz_result/            # Папка с результатами CLI-обработки
└── student_assistant/
    └── data/
        └── lecture_faq.json # FAQ-база знаний для квизов по категориям и темам
```

> Путь к `lecture_faq.json` задан в коде через `FAQ_PATH`. Если структура проекта отличается, обновите путь в `teacher_bot.py`.

## Установка

Склонируйте репозиторий:

```bash
git clone https://github.com/username/repository-name.git
cd repository-name
```

Создайте и активируйте виртуальное окружение:

```bash
python -m venv venv
```

Для Linux/macOS:

```bash
source venv/bin/activate
```

Для Windows:

```bash
venv\Scripts\activate
```

Установите зависимости:

```bash
pip install python-dotenv python-telegram-bot google-genai PyPDF2 python-docx
```

## Настройка переменных окружения

Создайте файл `.env` в корне проекта:

```env
TELEGRAM_TOKEN=your_telegram_bot_token
GEMINI_API_KEY=your_gemini_api_key
GEMINI_MODEL=models/gemini-2.5-flash
PROXY_URL=
```

Описание переменных:

| Переменная | Обязательная | Описание |
|---|---:|---|
| `TELEGRAM_TOKEN` | Да | Токен Telegram-бота от BotFather |
| `GEMINI_API_KEY` | Да | API-ключ Google Gemini |
| `GEMINI_MODEL` | Нет | Модель Gemini, по умолчанию `models/gemini-2.5-flash` |
| `PROXY_URL` | Нет | HTTP/HTTPS-прокси, если нужен для подключения |

> Не коммитьте `.env` в репозиторий. Добавьте его в `.gitignore`.

## Команды бота

| Команда | Описание |
|---|---|
| `/start` | Показывает приветствие и краткую инструкцию |
| `/categories` | Показывает список категорий из FAQ-базы |
| `/quiz_faq <категория>` | Генерирует квиз по выбранной категории |

Также можно отправить документ в чат с ботом. Бот скачает файл, обработает его и начнет квиз.

## CLI-режим обработки документа

`pipeline.py` можно использовать отдельно от Telegram-бота:

```bash
python pipeline.py --input path/to/file.txt --output_dir quiz_result --num_questions 5
```

Аргументы:

| Аргумент | Описание |
|---|---|
| `--input` | Путь к входному файлу |
| `--output_dir` | Папка для сохранения результата, по умолчанию `quiz_result` |
| `--num_questions` | Количество вопросов, по умолчанию `5` |

После успешной обработки будут созданы файлы:

```text
quiz_result/
├── chunks.jsonl # чанки исходного документа
└── quiz.json    # сгенерированный квиз
```

## Формат FAQ-базы

Файл `lecture_faq.json` должен содержать список объектов:

```json
[
  {
    "category": "Python",
    "topic": "Основы языка",
    "question": "Что такое переменная?",
    "answer": "Переменная — это имя, которое ссылается на значение в памяти."
  }
]
```

Поля `category` и `topic` используются для выбора раздела и темы через кнопки Telegram. Поля `question` и `answer` используются как источник для генерации тестовых вопросов.

## Формат сгенерированного вопроса

Каждый вопрос имеет структуру:

```json
{
  "id": 1,
  "question": "Текст вопроса",
  "options": ["Вариант A", "Вариант B", "Вариант C", "Вариант D"],
  "correct": 0,
  "explanation": "Пояснение правильного ответа",
  "source_chunk_id": null
}
```

Где `correct` — индекс правильного ответа от `0` до `3`.

## Ограничения

- Максимальный размер документа — 50 KB.
- Поддерживаемые форматы документов: `.txt`, `.pdf`, `.docx`.
- Для PDF и DOCX нужны дополнительные библиотеки: `PyPDF2` и `python-docx`.
- Если Gemini вернет некорректный JSON, квиз не будет создан.
- Для FAQ-квизов поле `source_chunk_id` всегда равно `null`.

## Как работает проект

1. Пользователь отправляет документ или выбирает категорию/тему из FAQ.
2. Текст документа разбивается на чанки.
3. Gemini получает текст или FAQ-записи и генерирует вопросы в JSON-формате.
4. Бот отправляет вопрос пользователю и показывает варианты ответа.
5. После выбора ответа бот сообщает, верно ли решение, показывает объяснение и переходит к следующему вопросу.
6. В конце бот показывает итоговый счет.
